# Knowledge Base

The base of my knowledge, written out, to be utilized by the wider world. Or their AI, I guess. 

## Structure

The Knowledge Base is structured to answer the following questions: 

| folder     | Contents              |
|------------|-----------------------|
| Concepts   | What is something?    |
| Decisions  | Why do something?     |
| Failures   | What something broke? |
| Procedures | How to do something?  |
